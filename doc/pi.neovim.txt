1. INTRODUCTION                                        *pi-intro*

pi.neovim is a zero-dependency Neovim wrapper that runs the native pi coding
agent TUI (https://pi.dev) in a centered rounded float terminal — the same
pattern as opencode terminal integrations.

Requirements: Neovim >= 0.10, pi CLI >= 0.84 in PATH.

Press `,ai` (or `:Pi`) to open. The float shows the full native pi TUI; closing
the window keeps the pi process alive, so reopening is instant.

==============================================================================
2. COMMANDS                                                  *pi-commands*

:Pi               Toggle the float terminal open/closed.
:PiToggle         Same as :Pi.
:PiTermCopy       Copy the terminal scrollback to the clipboard. Handy for
                  grabbing transient TUI warning/error text before it clears.

Recommended global keymap (Leader is `,`):

    ,ai            toggle the float terminal

==============================================================================
3. CONFIGURATION                                            *pi-config*

require('pi').setup({ ... })

executable      pi CLI command name. Default "pi".
window.width    Float width ratio of columns. Default 0.85.
window.height   Float height ratio of lines. Default 0.85.
window.border   Float border style. Default "rounded".
warm_start      Preload pi in the background so the first open is instant.
                Default false.
warm_start_delay Warm-up delay in ms. Default 2000.
